# Phase 3.4 Context Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Blend memory, code, and dependency evidence into `brain_context`'s single, budget-enforced response, without adding a new MCP tool, without fabricating memory records for code, and without breaking existing memory-only callers.

**Architecture:** Late normalization. Memory keeps `ContextItem` untouched through the existing `retrieval -> rank -> compileContext` path. Code keeps `CodeSearchResult` untouched through `CodeRetrievalService` + `computeScore`. Dependency facts keep `DependencyGraphService`'s native shape. Only inside one new pure function (`selectSources`) do all three convert to a common wrapper for budget competition; a generalized `fillBudget` core (extracted from the existing `optimizeContext`, which becomes a thin wrapper over it) enforces the one token budget; the result splits back into three typed, additive response fields.

**Tech Stack:** TypeScript, Zod, better-sqlite3, Node's built-in test runner (`node:test`), the existing monorepo's package/build/test conventions (see any existing `package.json` in `packages/*` for the exact script shape to copy).

**Spec:** `docs/PHASE_3_SPEC.md`, section "Phase 3.4 Spec — Context Integration" (everything from `## Part D — Pre-flight Findings` to `## Explicitly Not Implemented in 3.4`). Read it before starting Task 1 — this plan implements it task-by-task but does not repeat its rationale.

## Global Constraints

- Zero required network calls (existing invariant — nothing in this plan adds one).
- `packages/core/context` and `packages/core/token` may depend only on `@brain/contracts` (+ `@brain/compression` for token) — never on `@brain/codebase` or `@brain/retrieval`. Only `@brain/gateway` imports those directly.
- No new `brain_*` MCP tool. `packages/mcp/src/boundaries.test.ts` must keep passing unmodified (exactly 10 `registerTool` calls, one `gateway.*` call per handler).
- `ContextItem`'s shape is never changed. Code/dependency data never populates a `memoryId`/`type`/`confidence` field.
- `context_events` / `context_event_memories` (existing tables/schemas) are never modified. New telemetry is additive only (`context_event_sources`, migration `0006`).
- `brain_feedback`'s schema is never changed — code/dependency items are not feedback-able this phase.
- Every existing test (638 as of the end of Phase 3.3) must stay green throughout. Run `npm test` after every task, not just at the end.
- Follow existing conventions exactly: `.strict()` zod schemas for persisted/validated records, plain `interface` for internal summary types (matching `IndexResult`/`CodeSyncResult`/`DependencySyncResult`), `node --test` via `pretest`/`tsc -p tsconfig.test.json` compile-then-run, Fake-in-`@brain/test-fixtures` + Sqlite-in-`@brain/storage` for every store interface.

```ts
import type { TokenBudget } from "@brain/contracts";

export interface FillableItem {
  content: string;
  rank: number;
  wasCompressed: boolean;
}

export interface FillResult<T extends FillableItem> {
  included: T[];
  tokenCount: number;
  truncated: boolean;
  omittedCount: number;
}

/**
 * The one and only token-budget enforcement algorithm in the Brain. Extracted
 * from what was optimizeContext's body verbatim (Phase 1) so that Phase 3.4's
 * heterogeneous optimizeSources can share it exactly rather than reimplementing
 * budget arithmetic a second time -- see PHASE_3_SPEC.md Phase 3.4,
 * Token-Budget Integration. Two-pass greedy fill, in `items`' given array
 * order (never re-sorted by this function except the final rank-order pass):
 * pass 1 includes everything that fits as-is; pass 2 tries compressing
 * whatever didn't fit, into whatever budget pass 1 left over. See
 * optimize.ts's original doc comment (still present on optimizeContext) for
 * why the two passes are split rather than combined.
 */
export function fillBudget<T extends FillableItem>(
  items: T[],
  budget: TokenBudget,
  estimate: (text: string) => number,
  compressFn: (content: string, targetTokens: number, estimate: (text: string) => number) => { content: string; wasCompressed: boolean },
  identify: (item: T) => string,
): FillResult<T> {
  const included: T[] = [];
  const unfitted: { item: T; cost: number | null }[] = [];
  let tokenCount = 0;

  for (const item of items) {
    const remaining = budget.maxTokens - tokenCount;
    if (remaining <= 0) {
      unfitted.push({ item, cost: null });
      continue;
    }
    let cost: number;
    try {
      cost = estimate(item.content);
    } catch (error) {
      console.warn(`token estimation failed for ${identify(item)}, omitting it:`, error);
      unfitted.push({ item, cost: null });
      continue;
    }
    if (cost <= remaining) {
      included.push(item);
      tokenCount += cost;
    } else {
      unfitted.push({ item, cost });
    }
  }

  let omittedCount = 0;
  for (const { item, cost } of unfitted) {
    const remaining = budget.maxTokens - tokenCount;
    if (remaining <= 0 || cost === null) {
      omittedCount++;
      continue;
    }
    let compressed: { content: string; wasCompressed: boolean };
    try {
      compressed = compressFn(item.content, remaining, estimate);
    } catch (error) {
      console.warn(`compression failed for ${identify(item)}, omitting it:`, error);
      omittedCount++;
      continue;
    }
    if (compressed.wasCompressed) {
      let compressedCost: number;
      try {
        compressedCost = estimate(compressed.content);
      } catch (error) {
        console.warn(`post-compression estimation failed for ${identify(item)}, omitting it:`, error);
        omittedCount++;
        continue;
      }
      if (compressedCost <= remaining) {
        included.push({ ...item, content: compressed.content, wasCompressed: true });
        tokenCount += compressedCost;
        continue;
      }
    }
    omittedCount++;
  }

  included.sort((a, b) => a.rank - b.rank);

  return {
    included,
    tokenCount,
    truncated: omittedCount > 0 || included.some((i) => i.wasCompressed),
    omittedCount,
  };
}
```

import type { DependencyFact, DependencyRelation } from "@brain/contracts";

/** Compact code provenance -- no decorative wrapping, per PHASE_3_SPEC.md Context Formatting. */
export function formatCodeContent(chunk: { relativePath: string; startLine: number; endLine: number; content: string }): string {
  return `[CODE] ${chunk.relativePath}:${chunk.startLine}-${chunk.endLine}\n${chunk.content}`;
}

const RELATION_VERBS: Record<Exclude<DependencyRelation, "impact">, string> = {
  dependency: "directly imports",
  dependent: "is directly imported by",
};

/**
 * One formatted block per (seedFile, relation) group -- multiple related files
 * share one header, avoiding per-fact header repetition (PHASE_3_SPEC.md
 * Dependency Enrichment). Epistemic language is exact: "directly imports" /
 * "is directly imported by" / "transitively depends on ... at depth N" --
 * never "will break" (preserves 3.3's own boundary).
 */
export function formatDependencyContent(seedRelativePath: string, relation: DependencyRelation, facts: DependencyFact[]): string {
  const paths = facts.map((f) => `- ${f.relativePath}`).join("\n");
  if (relation === "impact") {
    const depth = facts[0]?.depth ?? 1;
    return `[POTENTIAL IMPACT] ${seedRelativePath} transitively depends on this file at depth ${depth}:\n${paths}`;
  }
  return `[DEPENDENCY] ${seedRelativePath} ${RELATION_VERBS[relation]}:\n${paths}`;
}

```ts
import type { ContextItem, CodeContextItem, DependencyContextItem, ContextSourceWrapper, DependencyExpansionPolicy } from "@brain/contracts";
import { DEFAULT_DEPENDENCY_EXPANSION_POLICY } from "@brain/contracts";

type Tier1Entry =
  | { sourceType: "memory"; item: ContextItem; score: number }
  | { sourceType: "code"; item: CodeContextItem; score: number };

const GUARANTEE_WINDOW = 3;

function tier1Id(entry: Tier1Entry): string {
  return entry.sourceType === "memory" ? entry.item.memoryId : entry.item.chunkId;
}

function sortTier1(entries: Tier1Entry[]): Tier1Entry[] {
  return [...entries].sort((a, b) => {
    if (b.score !== a.score) return b.score - a.score;
    const aId = tier1Id(a);
    const bId = tier1Id(b);
    return aId < bId ? -1 : aId > bId ? 1 : 0;
  });
}

/**
 * Ordering guarantee, not an inclusion guarantee (inclusion depends on the
 * token budget, unknown at this pure-selection stage -- see PHASE_3_SPEC.md
 * Mixed-Source Prioritization). If a source has >=1 candidate but none land in
 * the top GUARANTEE_WINDOW positions purely from score-scale mismatch, its
 * single best item is promoted into the last window position -- but never when
 * the other source would be pushed out of the window entirely (never demote a
 * source's only representative).
 */
function applyStarvationSafetyNet(sorted: Tier1Entry[]): Tier1Entry[] {
  const window = sorted.slice(0, GUARANTEE_WINDOW);
  const has = (list: Tier1Entry[], type: "memory" | "code"): boolean => list.some((e) => e.sourceType === type);

  for (const type of ["memory", "code"] as const) {
    const other = type === "memory" ? "code" : "memory";
    if (has(sorted, type) && !has(window, type) && has(window, other)) {
      const bestIndex = sorted.findIndex((e) => e.sourceType === type);
      if (bestIndex >= GUARANTEE_WINDOW) {
        const copy = [...sorted];
        const [best] = copy.splice(bestIndex, 1);
        copy.splice(GUARANTEE_WINDOW - 1, 0, best as Tier1Entry);
        return copy;
      }
    }
  }
  return sorted;
}

export function selectSources(
  memoryItems: ContextItem[],
  codeItems: CodeContextItem[],
  dependencyItemsBySeedFileId: Map<string, DependencyContextItem[]>,
  policy: Pick<DependencyExpansionPolicy, "maxDependencySeedFiles"> = DEFAULT_DEPENDENCY_EXPANSION_POLICY,
): ContextSourceWrapper[] {
  const tier1: Tier1Entry[] = [
    ...memoryItems.map((item): Tier1Entry => ({ sourceType: "memory", item, score: item.score })),
    ...codeItems.map((item): Tier1Entry => ({ sourceType: "code", item, score: item.score })),
  ];
  const ordered = applyStarvationSafetyNet(sortTier1(tier1));

  const result: ContextSourceWrapper[] = [];
  let seedsUsed = 0;
  for (const entry of ordered) {
    if (entry.sourceType === "memory") {
      result.push({ sourceType: "memory", content: entry.item.content, rank: 0, wasCompressed: entry.item.wasCompressed, item: entry.item });
      continue;
    }
    result.push({ sourceType: "code", content: entry.item.content, rank: 0, wasCompressed: entry.item.wasCompressed, item: entry.item });
    if (seedsUsed < policy.maxDependencySeedFiles) {
      seedsUsed++;
      for (const dep of dependencyItemsBySeedFileId.get(entry.item.fileId) ?? []) {
        result.push({ sourceType: "dependency", content: dep.content, rank: 0, wasCompressed: dep.wasCompressed, item: dep });
      }
    }
  }

  return result.map((w, index) => ({ ...w, rank: index + 1 }));
}

  /** Bounded, scope-native code retrieval + scoring. Never throws -- a failure degrades to no code items. */
  private async getCodeItems(task: string, scope: GetContextRequest["scope"]): Promise<CodeContextItem[]> {
    if (!this.codeRetrieval) return [];
    let results: CodeSearchResult[];
    try {
      results = await this.codeRetrieval.getCandidates({ text: task, scope, limit: DEFAULT_CODE_CANDIDATE_LIMIT });
    } catch (error) {
      console.warn("brain_context: code retrieval failed, continuing without code context:", error);
      return [];
    }
    const scored = results
      .map((r) => ({ result: r, score: computeScore(r.signals, DEFAULT_RANKING_WEIGHTS) }))
      .sort((a, b) => (b.score !== a.score ? b.score - a.score : a.result.chunkId < b.result.chunkId ? -1 : 1));
    return scored.map(({ result, score }, index): CodeContextItem => ({
      sourceType: "code",
      chunkId: result.chunkId,
      repositoryId: result.repositoryId,
      fileId: result.fileId,
      relativePath: result.relativePath,
      language: result.language,
      startLine: result.startLine,
      endLine: result.endLine,
      content: formatCodeContent(result),
      score,
      rank: index + 1,
      wasCompressed: false,
    }));
  }

  /** Bounded dependency enrichment for the given (already tier-1-ordered) seed code items. Never throws. */
  private async getDependencyItemsBySeed(codeItems: CodeContextItem[]): Promise<Map<string, DependencyContextItem[]>> {
    const byFileId = new Map<string, DependencyContextItem[]>();
    if (!this.dependencyGraph) return byFileId;
    const policy = DEFAULT_DEPENDENCY_EXPANSION_POLICY;

    for (const seed of codeItems.slice(0, policy.maxDependencySeedFiles)) {
      const items: DependencyContextItem[] = [];
      try {
        const deps = (await this.dependencyGraph.dependenciesOf(seed.repositoryId, seed.fileId)).slice(0, policy.maxDirectDependenciesPerFile);
        if (deps.length > 0) items.push(this.buildDependencyItem(seed, "dependency", deps.map((d) => ({ ...d, depth: null }))));

        const dependents = (await this.dependencyGraph.dependentsOf(seed.repositoryId, seed.fileId)).slice(0, policy.maxDirectDependentsPerFile);
        if (dependents.length > 0) items.push(this.buildDependencyItem(seed, "dependent", dependents.map((d) => ({ ...d, depth: null }))));

        const impact = (await this.dependencyGraph.impactOf(seed.repositoryId, seed.fileId, { maxDepth: policy.maxImpactDepth })).slice(0, policy.maxImpactItems);
        if (impact.length > 0) items.push(this.buildDependencyItem(seed, "impact", impact));
      } catch (error) {
        console.warn(`brain_context: dependency enrichment failed for ${seed.relativePath}, continuing without it:`, error);
        continue;
      }
      if (items.length > 0) byFileId.set(seed.fileId, items);
    }
    return byFileId;
  }

  private buildDependencyItem(
    seed: CodeContextItem,
    relation: "dependency" | "dependent" | "impact",
    facts: (DependencyRef & { depth: number | null })[] | ImpactRef[],
  ): DependencyContextItem {
    const normalized = facts.map((f) => ({ fileId: f.fileId, relativePath: f.relativePath, depth: "depth" in f ? f.depth : null }));
    return {
      sourceType: "dependency",
      repositoryId: seed.repositoryId,
      seedFileId: seed.fileId,
      seedRelativePath: seed.relativePath,
      relation,
      facts: normalized,
      content: formatDependencyContent(seed.relativePath, relation, normalized),
      rank: 0,
      wasCompressed: false,
    };
  }
```

  async getContext(request: GetContextRequest): Promise<ContextDelivery> {
    this.requireNonEmpty(request.task, "task");

    let candidates: Candidate[];
    const retrievalStart = performance.now();
    try {
      candidates = await this.retrieval.getCandidates({ text: request.task, scope: request.scope, limit: DEFAULT_CANDIDATE_LIMIT });
    } catch (error) {
      throw this.wrapUnexpected(error, "retrieval failed");
    }
    const retrievalMs = performance.now() - retrievalStart;

    const rankingStart = performance.now();
    const rankedResults: RankedResult[] = rank({ candidates, task: request.task });
    const rankingMs = performance.now() - rankingStart;

    let redundancyPairs: SimilarityPair[] = [];
    if (this.redundancy.enabled) {
      try {
        redundancyPairs = await this.retrieval.getRedundancyPairs(rankedResults, this.redundancy);
      } catch (error) {
        console.warn("brain_context: redundancy detection failed, continuing without it:", error);
      }
    }

    const compileStart = performance.now();
    const compiledContext = compileContext({ task: request.task, scope: request.scope, rankedResults, redundancyPairs });
    const compileMs = performance.now() - compileStart;

    const codeItems = await this.getCodeItems(request.task, request.scope);
    const dependencyItemsBySeed = await this.getDependencyItemsBySeed(codeItems);

    const optimizeStart = performance.now();
    let contextPack: ContextPack;
    let deliveredCodeItems: CodeContextItem[] | undefined;
    let deliveredDependencyItems: DependencyContextItem[] | undefined;

    if (codeItems.length === 0 && dependencyItemsBySeed.size === 0) {
      contextPack = optimizeContext(compiledContext, request.budget);
    } else {
      const wrappers = selectSources(compiledContext.items, codeItems, dependencyItemsBySeed);
      const filled = optimizeSources(wrappers, request.budget);
      const memoryItems: ContextItem[] = [];
      const codeOut: CodeContextItem[] = [];
      const depOut: DependencyContextItem[] = [];
      for (const w of filled.items) {
        if (w.sourceType === "memory") memoryItems.push({ ...w.item, content: w.content, wasCompressed: w.wasCompressed });
        else if (w.sourceType === "code") codeOut.push({ ...w.item, content: w.content, wasCompressed: w.wasCompressed });
        else depOut.push({ ...w.item, content: w.content, wasCompressed: w.wasCompressed });
      }
      contextPack = { items: memoryItems, tokenCount: filled.tokenCount, truncated: filled.truncated, omittedCount: filled.omittedCount };
      deliveredCodeItems = codeOut.length > 0 ? codeOut : undefined;
      deliveredDependencyItems = depOut.length > 0 ? depOut : undefined;
    }
    const optimizeMs = performance.now() - optimizeStart;

    let contextId: string | null = null;
    try {
      const retrievalEvent = await this.events.recordRetrieval({
        scope: request.scope,
        queryText: request.task,
        candidateIds: candidates.map((c) => c.memoryId),
        taskId: request.taskId ?? null,
      });

      const includedIds = new Set(contextPack.items.map((i) => i.memoryId));
      const contextEvent = await this.events.recordContext({
        retrievalEventId: retrievalEvent.id,
        scope: request.scope,
        taskId: request.taskId ?? null,
        includedMemoryIds: [...includedIds],
        omittedMemoryIds: candidates.map((c) => c.memoryId).filter((id) => !includedIds.has(id)),
        tokenCount: contextPack.tokenCount,
        memories: this.membershipRows(candidates, contextPack),
        candidateCount: candidates.length,
        candidateTokenCount: this.candidateTokenCount(candidates),
        retrievalMs: Math.round(retrievalMs),
        rankingMs: Math.round(rankingMs),
        compileMs: Math.round(compileMs),
        optimizeMs: Math.round(optimizeMs),
      });
      contextId = contextEvent.id;

      const sourceRows = this.buildContextEventSources(codeItems, dependencyItemsBySeed, deliveredCodeItems, deliveredDependencyItems);
      if (sourceRows.length > 0) {

          await this.events.recordContextSources(contextEvent.id, sourceRows);

import { SqliteMemoryRepository } from "@brain/storage";
import { SqliteRetrievalStore } from "@brain/storage";
import { SqliteEventStore } from "@brain/storage";
import { LocalEmbeddingProvider } from "@brain/storage";
import { SqliteCodeSearchStore } from "@brain/storage";
import { SqliteCodeDependencyStore } from "@brain/storage";
import { SqliteCodebaseRepository } from "@brain/storage";
import { MemoryService } from "@brain/memory";
import { RetrievalService, DEFAULT_NEAR_DUPLICATE_POLICY } from "@brain/retrieval";
import { CodeRetrievalService } from "@brain/retrieval";
import { EventService } from "@brain/learning";
import { DependencyGraphService } from "@brain/codebase";
import { Gateway } from "@brain/gateway";

export interface Brain {
  gateway: Gateway;
  close(): void;
}

export function createBrain(dbPath: string): Brain {
  const db = openDatabase(dbPath);
  const embeddings = new LocalEmbeddingProvider();

  const memoryRepository = new SqliteMemoryRepository(db.raw, embeddings);
  const retrievalStore = new SqliteRetrievalStore(db.raw, embeddings, db.vectorSearchAvailable);
  const eventStore = new SqliteEventStore(db.raw);
  const codebaseRepository = new SqliteCodebaseRepository(db.raw);
  const codeSearchStore = new SqliteCodeSearchStore(db.raw, embeddings, db.vectorSearchAvailable);
  const codeDependencyStore = new SqliteCodeDependencyStore(db.raw);

  const gateway = new Gateway(
    new MemoryService(memoryRepository),
    new RetrievalService(retrievalStore),
    new EventService(eventStore),
    { vectorSearchAvailable: db.vectorSearchAvailable },
    { enabled: false, ...DEFAULT_NEAR_DUPLICATE_POLICY },
    new CodeRetrievalService(codeSearchStore),
    new DependencyGraphService(codebaseRepository, codeDependencyStore),
  );

  return { gateway, close: () => db.close() };
}
